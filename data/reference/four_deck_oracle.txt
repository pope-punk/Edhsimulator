MAGIC: THE GATHERING — FOUR-DECK FULL CARD REFERENCE
Snapshot date: 2026-09-01
Reference version: v3 — mana costs + full type lines + stored Oracle/rules text

PURPOSE
-------
Validation reference for the four-player EDH simulation pod:
  • Reaminatour — Aminatou, Veil Piercer
  • Minsc & Boo, Timeless Heroes
  • Omo, Queen of Vesuva
  • Elenda, Saint of Dusk

DECK SNAPSHOTS
--------------
• Reaminatour: current project 100-card snapshot based on Archidekt deck 16760747, with user-directed updates through 2026-09-01.
• Minsc & Boo: frozen EDHREC-average snapshot used by the simulation pod.
• Omo: frozen EDHREC Lands Matter average snapshot used by the simulation pod.
• Elenda: exact user-supplied 100-card list used by the simulation pod.

ENTRY FORMAT
------------
Each card entry explicitly stores:
  Quantity
  Mana cost
  Full type line
  Oracle/rules text

For Rooms, transforming double-faced cards, modal double-faced cards, and Battles that transform,
both faces/doors are kept in the same deck entry. Face metadata is separated by “//” where applicable.
Lands use Mana cost: —.
Flavor text and card-specific rulings are omitted.
The Rules text field is the stored Oracle/rules-text basis used by the simulations; established-keyword
reminder text may be absent where Oracle text normally omits it.

INTEGRITY
---------
4 decks × 100 physical cards = 400 deck slots.
334 unique card names across the four decks.
Every distinct entry has explicit metadata and a nonempty rules-text body.
