# Rules support and release gate

The ledger is a purpose-built model for these four exact decks, not a comprehensive Magic rules engine. Exactness grows through encountered-game regressions: when a live position exposes an unsupported or incorrectly simplified interaction, stop the cohort, add the handler and a focused test, then replay from the accepted tape.

Current named regressions include:

- Death Grasp deals X to one externally selected target and produces one X-point life-gain event.
- Fetchlands activate separately from the land play, pay/sacrifice as a cost, expose only lands with the fetch’s printed basic land types, ask for the land, ask about shock-land life payment, and shuffle.
- Gruul Turf and Simic Growth Chamber enter tapped and require an externally selected land return.
- Aminatou miracle eligibility resets for every player each turn; casting is offered at the miracle trigger window, and X is externally selected.
- Scry/surveil disposition is externally selected in the official layer.
- Glen Elendra Archmage is offered as a noncreature-spell response, costs `{U}` plus sacrifice, and persists only when it died without a `-1/-1` counter.
- Domri enters with three loyalty; `+1` color and `-2` fight targets are externally selected, and the creature-spell uncounterable effect is tracked for the turn.
- APNAP priority windows exist at each phase/step boundary, on spells and trigger batches, and on both sides of combat declarations. Seats without legal actions are skipped; an action resets passes.
- Revision 5 can pass on any nonempty subset of eligible instant-speed source objects in one answer, with an independent `N beginning|end of PHASE` wake schedule per UID and atomic validation of the whole batch. `1` means the next matching pod-wide boundary. Revision 1–4 keeps the sole-source typed follow-up. A passed source does not open questions before its deadline, but remains explicitly wakeable when another source opens one; using it or changing zones/controller clears the schedule. At any later decision, its pilot can privately review all live schedules, unsnooze one or all, or reschedule one. These replayable controls return to the same decision, never manufacture priority, and are stored with the eventual answer row.
- Revision 5 spellcasting answers may request autoresolve. It reuses whole-stack autopass only for a spell cast onto an empty stack, preserves every opponent's interaction window, and wakes the caster if a new spell is cast. A postcombat-main PASS may instead carry SNOOZE ALL with an optional standard wake schedule; without one, it lasts through the turn immediately preceding that pilot's next turn. It auto-passes optional prompts, wakes for an attack before blockers, and wakes rather than inventing any mandatory choice.
- Revision-2 games expose `CONCEDE` on every already-open priority/specialized response request without manufacturing prompts for seats that have no other legal action. Player-leaves cleanup removes controlled stack objects, returns borrowed permanents, and preserves the last-player-standing result; Reaminatour elimination retains the gauntlet's focal-game stop. Revision-1 games keep the legacy upkeep prompt.
- Revision-3-and-later main-action requests keep `TABLE TALK (NON-MATERIAL)` available until used or the phase ends. Address mode, optional named recipient, and the complete 300-character message are submitted with the selected action, eliminating the compose decision. Revision 4 requires each pilot's first-own-turn precombat-main post to be a personality-shaped, strategically unrevealing generic salutation before material play; it prompts no responses. Addressed later messages may give each addressee one optional public generic response; replies never recurse, and play returns to main action with that phase's window closed. Revision-2 replay retains its dedicated compose step. Later decisions show recent transcript context, while `inspect messageboard` exposes the complete replay-derived public transcript. All table talk is explicitly untrusted speech, not rules or hidden information.
- A pilot can propose a demonstrated combo from a main-action or priority decision. Every other living pilot must explicitly confirm it has no disruption before the game pauses for a separate rules adjudication. The hash-bound response may only damage players, set life, or bounce a declared permanent scope; arbitrary state edits and stale responses fail closed.
- Parallax Wave activations may be stacked while retaining priority and resolve last-in-first-out. Linked return applies only if the exact Wave object is still on the battlefield when an activation exiles its target.
- Simultaneous upkeep, spell-cast, end-step, and life-gain trigger batches use externally selected per-controller ordering and APNAP placement.
- Legal instant-speed cards and activations across all four decks are audited neutrally. A discovered action without an exact handler is surfaced as a hard rules checkpoint and blocks if selected.
- Every material decision explicitly reminds the pilot that private-safe inspection is available without consuming the decision or priority.
- Legacy contract-1 planning only (current split roles follow AGENT_ARCHITECTURE_V1.md): each pilot's first keep/mulligan request automatically receives that pilot's private immutable seed plan plus branch-visible dynamic notes exactly once. Later requests expose a private `GAMEPLAN` query without persisting the returned plan into ordinary requests or checkpoints; eligible decisions additionally permit optional dynamic notes. In revision 3 and later, the first card a pilot draws each turn latches one non-priority planning checkpoint on that pilot's next decision. Its gameplay choice, mandatory complete Short-Term replacement, Long-Term KEEP/REVISE review and rationale, and conditional Long-Term replacement commit as one branch-bound batch. Revision 4 forces REVISE on each pilot's first own turn and requires the replacement to name each living opponent's posture. The immutable Standing Plan is reusable deck-piloting doctrine; Long-Term is the determinate match goal, opponent posture, alternatives, and pivot cues; Short-Term is concrete execution guidance synthesized from state, inspections, and rationale. Revision 2 retains the earlier own-main-phase long-term checkpoint. New cohorts snapshot all four editable seed files at initialization; discarded-branch dynamic notes are pruned and no other pilot receives seed or note text.
- Each pilot's editable `data/strategy/messaging_personalities/*.md` template is snapshotted immutably at the cohort/game activation boundary. Revision 3 and later inject it privately for first-draw planning, message-eligible main actions, and message responses; revision 2 retains compose/response-only delivery. It can shape voice, political posture, risk tolerance, and planning style but cannot override rules, known information, or deck doctrine.
- Gameplay rationale is required for spellcasting selections, activated-ability target choices, and trigger ordering, and optional elsewhere. Requests carry full bounded records for the same pilot's immediately previous decision and most recent rationalized decision without recursively nesting prompt history.
- Every decision reports modeled public mana for every player as one simultaneous total plus independent `W/U/B/R/G/C` maxima, using the same modeled source inventory as payment validation.

The static release gate verifies four 100-card decks, the current Liliana/Vesperlark baseline, absence of a strategic chooser in the official referee layer, and the Death Grasp separation. The test suite adds behavioral checks for single-target Death Grasp, fetch legality, bounce lands, persist, Domri loyalty, hidden-information redaction, branch rewind, private seed and dynamic gameplans, private messaging-personality snapshots, public messageboard chains and inspection, public mana projections, scheduled and privately managed object passes, upkeep concession, and bound combo adjudication.

Any `UnrefereedDecisionError` is game-breaking and never permits fallback to the historical deterministic pilot. The campaign rejects the uncommitted action, seals the accepted prefix as a draw, opens a rules repair work item, requires a skeptical learning pass after repair, and retains the draw as quarantined within its cohort before advancing.

Reaching the configured round horizon produces `horizon_stop` with no winner. The official manual path never uses the historical board/life heuristic to manufacture a result; increase the horizon and replay if a game needs more turns.
